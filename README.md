# Abdulla Sahed — Responsive Portfolio

A responsive portfolio recreated from the supplied HTML and design guide. It keeps the original dark canvas, electric-lime accent, typography, section order, project cards, and project-details dialog while adding a responsive mobile navigation menu. The site uses a fixed dark theme with no dark/light mode toggle.

## Run in VS Code
1. Extract this folder.
2. Open `abdulla-portfolio` in VS Code.
3. Install the **Live Server** extension if you do not already have it.
4. Right-click `index.html` → **Open with Live Server**.

You can also open `index.html` directly in a browser, but Live Server is recommended.

## Before publishing
- Add your real resume PDF at `assets/Abdulla_Sahed_Resume.pdf`. The Resume buttons link to this file.
- Update the placeholder phone/WhatsApp number (`8801700000000`) in `index.html`.
- The contact form opens the visitor's default email app with the message prefilled. For server-side delivery without an email app, connect a form service or backend.
- External font, icon, Tailwind CDN, image, and hosted-project links need an internet connection.
- Review skill percentages and project descriptions to make sure they accurately represent your current work.

## Files
- `index.html` — page markup
- `styles.css` — original styling plus responsive/mobile improvements
- `script.js` — project details dialog, mobile menu, email copy, contact form
- `assets/` — place your resume PDF here
